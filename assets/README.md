# RoofingnearmeSTL Brand Assets

## Logo Upload
Place your logo file here:
- **Logo file name:** `logo.png` or `logo.svg` (preferred: SVG for scalability)
- **Favicon:** `favicon.ico` or `favicon.png`
- **Recommended logo sizes:**
  - Header: 200px wide
  - Mobile: 150px wide
  - Favicon: 32x32px

## Brand Colors
Edit `brand-colors.json` with your company colors:
- Primary color: Main brand color (currently orange #ff6b00)
- Secondary color: Dark/accent color (currently ink #1a1e23)
- Other colors for UI elements

## How to Upload
1. Go to GitHub repo → assets folder
2. Click "Add file" → "Upload files"
3. Drag and drop your logo and brand files
4. Commit to the `lead-generation` branch

Once uploaded, update the file paths in the HTML files to reference your assets.
